# ORYX Owner Management System

## 1. Project Introduction

ORYX Owner Management System is a standalone Java console application developed to manage a small online shoe store.

The system helps the store owner manage inventory, customer orders, sales, profits, losses, and business reports.

This project focuses on Object-Oriented Programming (OOP) concepts and Java programming fundamentals.

## 2. Product Information

- **Brand:** ORYX
- **Product:** ORYX Classic
- **Price:** Rs. 8,500
- **Colours:** Black, White, Blue, Brown
- **Sizes:** 36–45
- **Total Product Variants:** 40

## 3. Main Features

- Dashboard Management
- Stock Management
- Order Management
- Sales and Profit Reports
- Product Performance Analysis
- District Analysis
- Inventory Overview
- Low Stock Alerts
- File-Based Data Storage

## 4. Business Rules

- Orders are managed manually by the owner using sample data.
- Stock is deducted when an order is created.
- Orders can have Pending, Dispatch, Complete, or Return statuses.
- Profit per completed shoe is Rs. 1,300.
- Delivery loss per returned order is Rs. 450.
- The owner decides whether returned shoes should be added back to stock.
